لصاحب الطلعة

جهّز طلعة جديدة

الخطوة الأولى: اربط الموقع بقاعدة بيانات مجانية من Google عشان تنحفظ أجوبة الشلة. تسوّيها مرة وحدة بس.

  1. ادخل console.firebase.google.com بحساب Google، واضغط Create a project. طفّي Analytics وكمّل.
  2. من القائمة: Build ثم Realtime Database، واضغط Create Database.
  3. اختر Belgium (europe-west1)، وبعدين Start in test mode، ثم Enable.
  4. انسخ الرابط اللي يطلع فوق (ينتهي بـ firebasedatabase.app) والصقه هني.
